# RGFTP

一个使用 [gpui-kit](https://gpui-kit.com) 构建的桌面`SFTP` 客户端，交互参考`Xftp`的双栏文件管理方式。

> 说明：本项目实现的是 **SFTP（SSH File Transfer Protocol）**，支持密码和 SSH 私钥两种登录方式。

## 功能

- **隐藏文件开关**：远程目录默认隐藏以 `.` 开头的文件，可通过远程工具栏的眼睛按钮显示 / 隐藏。
- **多服务器会话**：可以同时保持多台服务器连接，右侧窗口显示当前会话；双击已连接但非当前的服务器可切换，双击当前服务器断开。
- **连接状态**：所有已连接的服务器在左侧列表中显示绿色状态点，当前会话高亮显示。
- **拖拽排序**：左侧分组和连接都可以拖动调整顺序；拖动连接时还可以把它移到其他分组，拖动过程中会显示插入位置。
- **分组必选**：每个连接都必须属于一个分组；还没有分组时新建连接会先提示创建分组。
- **两种认证方式**：密码登录、SSH 私钥登录（支持带口令的私钥）。
- **主机密钥确认**：第一次连接某台服务器时不会自动信任，而是弹出确认框显示密钥类型和 SHA256 指纹，需手动选择「信任并保存」或「仅本次」；若服务器密钥与已保存的不一致，会以警告样式再次询问。信任记录保存在用户配置目录的 `known_hosts.json`。
- **双栏文件浏览**：左侧本地文件，右侧远程文件；双击进入目录，支持上级目录、主目录和刷新。
- **文件管理**：本地和远程文件都支持右键重命名、删除；远程文件还支持修改权限和查看详细信息;删除文件夹会递归删除其内容。
- **模糊搜索**：两个文件窗口各有一个搜索框，按文件名字符顺序进行不区分大小写的模糊匹配，输入即时过滤。
- **滚动条**：文件较多时两侧列表右侧显示滚动条，颜色跟随应用主题的浅色 / 深色。
- **拖拽传输**
  - 从左侧本地文件拖到右侧远程窗口：上传。
  - 从右侧远程文件拖到左侧本地窗口：下载。
  - 从系统文件管理器拖入远程窗口：上传。
  - 支持文件夹递归上传 / 下载。
  - 上传时若服务器当前目录已有同名文件 / 文件夹，会先弹出「文件已存在」确认框，选择覆盖或取消；弹框出现时会播放系统提示音，并在 Windows 任务栏图标上闪烁红色警告角标，提示处理完后自动停止并清除。
- **传输状态**：底部显示当前传输方向、文件名、实时速度、进度和结果；上传 / 下载结束（成功、取消、失败）时在右上角弹出彩色通知，成功 / 取消 3 秒后自动消失，错误提示保留 6 秒便于阅读原因。
- **任务栏进度**：上传 / 下载过程中，Windows 任务栏按钮会叠加显示传输进度；任务结束后自动清除。
- **取消传输**：上传 / 下载过程中可以点击进度条右侧的取消按钮，当前任务会在下一个数据块边界停止。已写入的部分文件会保留，需手动清理。
- **自定义标题栏**：不显示 Windows 原生标题栏，标题栏内集成应用品牌、连接状态、窗口最小化/最大化/关闭按钮。
- **主题**：首次启动自动跟随系统浅色 / 深色外观；右上角手动切换后会保存选择，后续启动使用保存的主题配置。切换时从按钮位置扩散一个圆形波纹，整页配色平滑过渡。
- **本地持久化**：连接、分组和上次打开的本地目录保存在用户配置目录。**为了让工具开箱即用，密码和私钥口令会以明文写入该 JSON 文件。**
  - Windows：`%APPDATA%\rgftp\profiles.json`
  - macOS：`~/Library/Application Support/rgftp/profiles.json`
  - Linux：`~/.config/rgftp/profiles.json`

## 项目结构

```text
src/
├── main.rs       应用入口、窗口和主题初始化
├── app.rs        GPUI 视图、对话框、拖拽与交互
├── backend.rs    后台`Tokio` 线程、`russh/russh-sftp` 传输
├── model.rs      连接、分组、配置和文件条目
├── theme_anim.rs 浅色 / 深色主题切换动画（配色插值与圆形扩散）
└── util.rs       路径、大小、时间等格式化工具
```

## 技术栈

- [gpui-kit](https://crates.io/crates/gpui-kit)：GPUI + GPUI Component UI 组件
- [russh](https://crates.io/crates/russh)：SSH 客户端
- [russh-sftp](https://crates.io/crates/russh-sftp)：SFTP 子系统
- [tokio](https://tokio.rs)：后台网络与文件 IO 运行时
- [serde](https://serde.rs)：连接配置序列化
